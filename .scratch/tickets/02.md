## Parent

Parent: #1 (Jumeau numérique immunitaire — Bilan Immuno Twin, MVP)

## What to build

The core simulation: given a bilan as the initial state, simulate the temporal evolution of the immune populations through the graphe de régulations and emit time trajectories as JSON.

This is the heart of the jumeau. The graphe de régulations has a fixed topology from immunology literature with the Th1/Th2/Th17 as separate nodes (plus CD8+, B, NK, Treg, monocytes). The ODE system uses fonctions de Hill for regulatory interactions (ADR-0001), computes cytokines as variables quasi-statiques (ADR-0005), and is integrated with an implicit solver (`solve_ivp` Radau) to handle stiffness over a configurable horizon with an adaptive steady-state stop. The MVP runs with literature default kinetic parameters — no patient calibration yet. The CLI emits trajectories of each population over time as JSON.

## Acceptance criteria

- [ ] The graphe de régulations with fixed topology and separate Th1/Th2/Th17 nodes is defined and testable.
- [ ] The ODE system uses fonctions de Hill (ADR-0001) and quasi-static cytokines (ADR-0005), integrated with an implicit solver (Radau) that remains stable on a stiff system.
- [ ] The CLI simulates from a bilan initial state and emits population-vs-time trajectories as JSON, for a configurable horizon and with an adaptive steady-state stop.
- [ ] Unit tests at the pure-math seam verify the fonctions de Hill (limits, saturation, thresholds) and ODE correctness; an integration test drives simulation through the CLI.
- [ ] ADR-0004 respected (CLI only).
