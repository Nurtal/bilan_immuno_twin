Parent: #1 (Jumeau numérique immunitaire — Bilan Immuno Twin, MVP)

## What to build

Calibrate patient-specific kinetic parameters from a single bilan: a `calibrate` CLI subcommand that estimates kinetic parameters via MAP with literature-derived priors and produces bootstrap confidence intervals (ADR-0002).

This is what makes the jumeau per-patient rather than generic: from the cytometric snapshot, estimate the parameters the ODE simulation (T2) uses, with quantified uncertainty. A single bilan suffices (no longitudinal history required) because the MAP prior keeps the problem identifiable. The CLI emits the calibrated parameters plus their bootstrap intervals, ready to feed the simulation.

## Acceptance criteria

- [ ] A `calibrate` CLI subcommand estimates patient-specific kinetic parameters from a bilan via MAP.
- [ ] The calibration uses literature-derived priors (ADR-0002), not full MCMC.
- [ ] Bootstrap confidence intervals are produced and emitted alongside the parameter estimates.
- [ ] Calibrated parameters are consumable by the simulation.
- [ ] Unit test at the pure-math seam: on synthetic data, MAP recovers known parameters and the bootstrap intervals contain the truth; integration test drives `calibrate` through the CLI.
