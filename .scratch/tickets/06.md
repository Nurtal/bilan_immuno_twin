## Parent

Parent: #1 (Jumeau numérique immunitaire — Bilan Immuno Twin, MVP)

## What to build

Validate the framework on synthetic data and pin it against regression: a self-consistency mode (fixed parameters → simulate with noise → recalibrate → recover parameters) and regression fixtures that pin simulation outputs across versions.

This proves the framework is sound before any clinical data (which is out of scope for the MVP). The self-consistency run confirms the calibration/simulation round-trips real parameters from noisy synthetic measurements. The regression fixtures catch obscure model changes that silently alter results.

## Acceptance criteria

- [ ] A self-consistency validation mode runs: fixed parameters → simulate → add noise → recalibrate → recover parameters to within tolerance.
- [ ] Regression fixtures pin simulation (and calibration) outputs so version changes that alter results are caught.
- [ ] Unit/integration tests drive the self-consistency run and detect a planted parameter/model change.
- [ ] The validation uses synthetic data only (no real clinical data in scope).
- [ ] ADR-0004 respected (CLI only).
