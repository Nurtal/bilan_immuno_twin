## Parent

Parent: #1 (Jumeau numérique immunitaire — Bilan Immuno Twin, MVP)

## What to build

The thinnest vertical tracer: a `bilan` CLI (ADR-0004, CLI-only) that loads a patient's bilan immunologique from a file and emits the measured immune populations as structured JSON.

This establishes the whole skeleton — the Python package scaffold, the CLI entry point, the chosen test runner, and the binding contract for a bilan (the initial state of a jumeau). Nothing is simulated yet; this ticket makes the plumbing from input file to CLI JSON output work end-to-end so later slices can hang off it. It must include unit tests at the pure-interfaces seam (parsing a bilan, mapping to the population set) and an integration test driving the CLI.

## Acceptance criteria

- [ ] A `bilan` CLI entry point exists and runs as an installable Python command.
- [ ] Given a bilan immunologique file, the CLI emits the immune populations (CD8+ T, CD4+ Th subsets, B, NK, Treg, monocytes) as structured JSON.
- [ ] The bilan input contract is defined and validated against the panel cytometrique (missing populations / malformed input produce a clear error).
- [ ] The test runner is chosen and wired; a unit test covers bilan parsing and an integration test drives the CLI end-to-end.
- [ ] ADR-0004 is respected: no notebook or API surface, CLI only.
