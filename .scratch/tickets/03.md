## Parent

Parent: #1 (Jumeau numérique immunitaire — Bilan Immuno Twin, MVP)

## What to build

Allow a clinician to apply an immunotherapy perturbation and see the immune response: extend the simulation with an immunotherapy catalogue (anti-PD1, anti-TNF, corticoïde) whose effect is modeled as a documented modification of kinetic parameters (ADR-0003).

The CLI accepts `--perturb <therapy>`, applies the parameter modification, and emits the perturbed trajectories alongside a what-if comparison against the unperturbed run. The perturbation catalogue is documented and interpretable (e.g., anti-PD1 raises CD8+ activation, anti-TNF reduces TNF-α effect, corticoïdes depress multiple pro-inflammatory signals). The perturbation input contract is validated (unknown therapy → clear error).

## Acceptance criteria

- [ ] An immunotherapy catalogue (anti-PD1, anti-TNF, corticoïde) maps each therapy to relative modifications of kinetic parameters (ADR-0003).
- [ ] The CLI `--perturb <therapy>` emits the perturbed trajectories and a comparison against the unperturbed run.
- [ ] The perturbation catalogue is documented and each entry is interpretable as a parameter change.
- [ ] Unknown/invalid perturbation identifiers produce a clear error.
- [ ] Unit tests cover the perturbation mapping; an integration test drives `--perturb` through the CLI.
- [ ] ADR-0004 respected (CLI only).
